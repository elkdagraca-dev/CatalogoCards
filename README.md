# CatalogoCards

Extensão nativa para Kodular e MIT App Inventor.

## Recursos

- Cards em modo vertical ou horizontal
- Imagem com proporção 2:3
- Título com HTML
- Subtítulo com HTML
- Reticências
- Quebra de linha
- Controle de número máximo de linhas
- Clique curto
- Clique longo
- Cache de imagens em memória
- Carregamento assíncrono de imagens

## Formato da lista

Cada item deve possuir 3 posições:

1. URL da imagem
2. Título em HTML
3. Subtítulo em HTML

Exemplo:

```text
[
  [
    "https://exemplo.com/poster.jpg",
    "<b>Breaking Bad</b>",
    "<font color='#2196F3'>SÉRIE</font> | 9.1 | 2008"
  ]
]
